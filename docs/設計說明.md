## 2. 模組說明

### F1 AFO 腳底件 v17（由 v15 修改）

- 外形、後跟杯、束帶扣環、鞋頭擋塊插槽、底部格柵都沿用 v15。
- 兩個感測器正下方 Ø46 範圍改成實心（z 0 → 15），受力可以直接經底板傳到地面。
- 感測器口袋：Ø32 孔（z 3 → 15），加 Ø42.4 × 4 沉台，以及 3 個 M2.5 熱熔螺母孔（Ø3.6）。
- 走線槽：寬 6、z 10 → 13.5，上面蓋 B2 走線蓋板（1.5 t，和底板齊平）。
  - 路線是 S1 → 往後跟 → 與 S2 的線會合 → 後跟杯背面的 Ø5 出線孔（z ≈ 11.75）。
  - 這段會從小腿件套筒底下通過，所以電線不會外露在鞋底摩擦面上。

### L1 小腿件 v15（不改）

- 下緣套筒插進後跟杯內側，用兩側螺絲固定。
- 套筒的內面同時是鞋跟的定位面。
- 背面放麵包板和 ESP32。

### T1 鞋頭擋塊（v15，9 種擇一）

- 依鞋長選 T6 / T9 / T12，依鞋頭高度選 H16 / H22 / H28。

### A4 魔鬼氈（38 mm × 2）

- 穿過托盤兩側的 v15 扣環（x ≈ 140、x ≈ 188），跨過鞋面。
- 小腿部分沿用 v15 的小腿束帶。

### C 鋼珠式 FSR 感測匣 × 2（剖面見 FSR-09）

整個感測匣鬆開 3 支 M2.5 就能從上方取出。

| 件號 | 說明 |
|---|---|
| C0 感測匣殼 | PETG。Ø42 凸環（高出底板 3）+ Ø27 導筒。內有 Ø12 止擋肩和 Ø21.4 頂唇；3 個 M2.5 沉頭孔（固定位置） |
| C1 TPU 導槽 | TPU 95A，外徑 Ø22，頂面 Ø21。有 Ø5.15 導槽孔，下緣是 Ø4.5 防脫唇 |
| C2 鋼珠 | Ø5，SUJ2 |
| C3 FSR 402 | 尾線朝走線槽方向引出 |
| C4 FSR 支撐座 | Ø22 × 1.5，PETG 100% 填充，或用鋁片 |
| C5 保護傳力片 | Ø10 × 0.5，SUS304，用轉印膠黏在 FSR 正中央 |

**鋼珠限位**：
- 側向：被導槽孔限制，只能上下移動。
- 往下：有防脫唇擋住。
- 整個導槽又被頂唇和止擋肩鎖在殼內，所以鋼珠不會脫出。

**受力路徑**：鞋底 → TPU 頂面 → 鋼珠 → 保護片 → FSR 中央 → 支撐座 → 腳底件底板 → 地面。

**過載保護**：
- TPU 被壓下的深度超過 Stop_Gap = 1.0 mm 時，外環會坐上止擋肩，多出來的力繞過 FSR。
- FSR 最大受力 ≈ 68.7 · δ^1.5 ≈ 69 N（以 TPU 95A 概算，必須校正）。

**注意**：腳跟的感測匣在小腿件套筒內側（嵌板外緣 y = 33.0，套筒內面 y = 33.2）。

### E 電子（小腿件背面，零件不改）

- 接線：每顆 FSR 串一顆 10 kΩ 接到 3.3 V，分壓點接 ESP32 ADC1（例如 GPIO34 / GPIO35）。
- FSR 線經 2 × JST-XH 2P 接到麵包板。
- 電源方式待確認（行動電源或 18650 模組）。

## 5. 組裝流程

1. **熱熔螺母**：在 F1 兩個口袋的沉台壓入 3 × M2.5 熱熔螺母。
2. **感測匣**（每組）：
   1. 把保護片黏在 FSR 正中央。
   2. FSR 放上支撐座，尾線對準殼體開口。
   3. 鋼珠壓進 TPU 導槽，壓過防脫唇。
   4. 導槽從上方壓入殼體，通過頂唇。
   5. 支撐座卡進殼體底部。
3. **放入感測匣**：放進口袋，選好偏心角度，鎖 3 × M2.5。FSR 尾線接上延長線，放進走線槽。
4. **走線**：延長線從後跟出線孔拉出，蓋上 B2 蓋板（用 2 點膠或過盈卡入）。
5. **小腿件**：裝回 L1（v15 原本的螺絲）。電線沿後跟杯背面往上，套上螺旋套管，用束線扣固定，接到麵包板。
6. **穿鞋**：選好鞋頭擋塊並插上，放入布鞋，扣上魔鬼氈和小腿束帶。

## 6. 測試流程

1. 零點檢查。
2. 單點靜態加載：0 到 40 kg 分階，加載、卸載各 3 次。
3. 隔著鞋底校正。
4. 全身體重靜態測試：雙腳站、單腳站、前傾、後傾。
5. 慢走約 100 步，確認重現性，並檢查潛變和螺絲鬆動。
6. 最後才接到外骨骼做步態量測。

1. 布鞋實測：鞋長、鞋寬、**鞋跟寬（必須 ≤ 66）**、Heel_Offset。
